## 3. 页面结构与交互设计

### 3.1 总体布局
- 最外层 `.layout`（flex 横向）：左侧 `.sidebar` + 右侧 `.main`。
- 左右均 `height:100vh; overflow:hidden`，各自内部滚动，互不干扰 → 满足“侧栏折叠后高度不变、不随右侧滚动移动”。
- 折叠状态：`.layout.collapsed .sidebar` 宽度变为最小（仅箭头按钮），`.main` 自动撑满。

### 3.2 左侧边栏（`.sidebar`）
1. **主界面头部**：标题「心奇学古文」（`#appTitle`，`cursor:pointer`）+ 副标题「小学 · 初中 1–9 年级全册」。**点击标题弹出信息弹窗** `#infoModal`：含「使用方法」与「应用信息（版本号 v1.0 / 更新日期 2026.8.26 / 作者 Peppa's Daddy）」；点关闭按钮、点遮罩空白处或按 `Esc` 均可关闭。
2. **学期选择**：`gradeSel`（年级 1~9 下拉）+ `termSel`（上/下册下拉），`change` 触发 `renderSide()`。
3. **折叠按钮** `collapseBtn`（`«`）：点击切换 `.layout.collapsed`；折叠时按钮变 `»`，用于手机端扩展右侧显示区。
4. **目录** `#sideNav`：当前学期篇目列表。每项结构：
   - 序号 `.idx` → 标题 `.ttl` → 右侧同行两个按钮 `.op.op-t`（教学解读）/ `.op.op-s`（全文掌握）。
   - 点击整行 = 进入「教学解读」；点击右侧按钮 = 进入对应页（事件 `stopPropagation`）。

### 3.3 右侧内容（`.main`）
- 顶部工具栏 `.toolbar`（**仅教学解读/全文掌握页都有**）：
  - `A−` / `100%` / `A+`：字体缩放，汉字与拼音通过 CSS 变量同步调整（`applyFont()`）。
  - `🖨 打印`：调用 `window.print()`；`@media print` 下隐藏侧栏、工具栏，并强制显示所有遮挡内容。
  - `全部显示`/`全部隐藏`：仅「全文掌握」页显示（`toggleAll()`）。
- 内容主体由 `teachHTML(p)`（教学解读）或 `selfHTML(p)`（全文掌握）生成。

### 3.4 两种页面内容
**教学解读页（teachHTML）**
1. 页头（标题+拼音、作者/朝代+拼音、背诵要求徽章）
2. 全文 · 标准拼音（`renderPoem`）
3. 注释（`renderNotes`，词语+释义）
4. 全文翻译（`trans`）
5. 教学解读：时代与作者背景（`bg`）+ 诗文好在何处（`gd`）
6. 必会字词（`renderWords`，上拼音下汉字）+ 课本背诵要求

**全文掌握页（selfHTML）**
1. 页头（**带遮挡**：标题、作者/朝代均遮）
2. 正文 · 标准拼音（`renderSelfBody`：按标点逐句遮）
3. 必会字词（`renderWords(...,true)`：拼音段、汉字段各自独立遮）

### 3.5 遮挡机制（R11 核心）
- 每个可遮单元用 `maskWrap(inner, cls)` 包裹：外层 `.mask` + 内容 `inner` + 覆盖层 `<span class="cover">`。
- `.mask .cover` 默认 `position:absolute` 盖住内容（灰块）；`.mask.show .cover` 透明消失 → 显示内容。
- 分句：`splitClauses()` 用正则 `PUNC = /[，。？！；：、]/` 切分正文为句子数组，每句一个 `.mask.clause`，点击逐句显示。
- 字词：拼音 `.w-py`、汉字 `.w-hz` 各包一个 `.mask.wseg`，点击各自独立显示。
- 全局开关：`toggleAll()` 遍历 `#main .mask` 判断是否全隐藏，决定一次性全显或全隐，并切换按钮文字。
- **重新进入默认遮挡**：`show()` 每次重新生成 `main.innerHTML`，DOM 全新 → 所有 `.mask` 天然回到未 `.show` 状态。无需额外重置逻辑。

## 4. 程序结构

单文件由三段组成：`<style>`（CSS）、`<body>`（骨架，含空容器 `#sideNav`/`#main` 等）、`<script>`（数据 + 逻辑）。

### 4.1 数据层
```js
var GRADES = ["一年级",...,"九年级"];        // 9 项
var POEMS = {
  "1s":[ {...}, {...} ],   // 一年级上册
  "1x":[ ... ],            // 一年级下册
  ...
  "9s":[ ... ], "9x":[ ... ]  // 九年级上/下
};
```
**学期 key 规则**：年级数字(1~9) + 学期字母(`s`=上, `x`=下)。共 18 个 key。

**单篇对象字段**：
| 字段 | 含义 | 示例 |
|------|------|------|
| `t` | 标题（纯汉字/含标点） | `"观沧海"` |
| `tp` | 标题拼音（空格分词，与 `t` 字数对齐） | `"guān cāng hǎi"` |
| `a` | 作者 / 出处 | `"曹操"` / `"《世说新语》"` |
| `ap` | 作者拼音 | `"cáo cāo"` |
| `d` | 朝代 | `"汉"` / `"唐"` / `"宋"` |
| `s` | 所属位置标签 | `"七年级上册 · 课文"` |
| `b` | 背诵要求 | `"背诵全文"` / `"背诵并默写"` |
| `L` | 正文数组：`[[中文句, 拼音句], ...]` | 详见 §5 |
| `n` | 注释：`[[词语, 释义], ...]` | |
| `tr` | 全文翻译（可含 `\n` 分段） | |
| `bg` | 时代与作者背景 | |
| `gd` | 诗文好在何处（赏析） | |
| `w` | 必会字词数组（纯汉字） | `["沧海","临"]` |
| `wp` | 必会字词拼音（与 `w` 等长对齐） | `["cāng hǎi","lín"]` |

**文言文长文说明**：初中长篇文言文（如《出师表》《岳阳楼记》）`L` 的个别句可能 `pyStr` 为空（`line[1]===''`），渲染时走 `.plain` 纯文本分段分支，难字读音在 `n`（注释）中标注。

### 4.2 关键函数（script 内）
| 函数 | 作用 |
|------|------|
| `curKey()` | 取当前 `gradeSel.value + termSel.value` |
| `isPunc(s)` | 判断字符是否为非拼音（标点/空格）→ 不注音 |
| `rubyText(text, pyStr)` | 生成「字+上标拼音」`<ruby>` 串（页头用） |
| `renderPoem(lines, cls)` | 渲染教学页正文（逐字 ruby；无拼音走 `.plain`） |
| `renderNotes(n)` | 渲染注释列表 |
| `renderWords(w, wp, masked)` | 渲染必会字词（上拼音下汉字；`masked` 时加遮挡） |
| `pageHead(p, masked)` | 页头（标题/作者/朝代；`masked` 时遮） |
| `splitClauses(line)` | 按标点切分正文为句（返回 `{c:[字],p:[音]}` 数组） |
| `clauseRuby(cl)` | 单句 ruby 渲染 |
| `maskWrap(inner, cls)` | 包裹遮挡层 |
| `renderSelfBody(lines)` | 全文掌握页正文（逐句遮） |
| `teachHTML(p)` / `selfHTML(p)` | 两页 HTML 生成 |
| `renderSide()` | 渲染左侧目录（绑定事件，默认打开第 1 篇教学解读） |
| `applyFont()` | 按 `fontScale` 写 CSS 变量（`--fs-*`/`--rt-*`） |
| `toolbarHTML()` | 顶部工具栏 HTML |
| `toggleAll()` | 全部显示/隐藏切换 |
| `show(i, m)` | 主渲染：组装工具栏+页面、绑定交互、滚动归顶 |

### 4.3 交互绑定要点
- 目录整行 `click` → `show(i,'t')`；`.op` 按钮 `click` 带 `stopPropagation` → `show(i, m)`。
- `show()` 每次重建 `#main`，因此字体按钮、打印、遮罩点击、全部显示等事件都在 `show()` 内重新绑定，避免重复绑定。
- 字体缩放范围 `FONT_MIN=0.7` ~ `FONT_MAX=1.6`，步长 `0.15`，通过 CSS 变量统一控制汉字与拼音。

## 5. 数据与拼音规范

### 5.1 对齐铁律（最重要）
- 每句 `L[i] = [中文, 拼音]`：**中文逐字数 === 拼音按空格分词数**。
- 拼音串用空格分隔每个字的读音；标点（，。？！；：、等）在中文里占 1 字，在拼音里对应空串或标点本身（`isPunc` 判断后不生成 `<rt>`）。
- `tp`/`ap` 必须与 `t`/`a` 字数对齐；`wp[i]` 必须与 `w[i]` 字数对齐。
- **校验脚本**（见 §6）逐篇比对，任一不对齐立即报错定位。

### 5.2 多音字按古文语境注音（示例）
- 不亦说乎 → 说(yuè)；风吹草低见牛羊 → 见(xiàn)
- 食马者 → 食(sì)；遗陛下 → 遗(wèi)；被甲 → 被(pī)
- 邪(yé)；与(yù，参与)；衣(yī，名词)；着(zhuó)
- 降(xiáng，投降)；教(jiāo，传授)；少女(shào，年少)；堙(yīn)

### 5.3 特殊字符处理
- 标题/作者含括号：如「悯农（其二）」「示儿」等，拼音串同样保留空格分词；下游 `rubyText` 仅对非标点的汉字注音，括号作为标点不注音。
- 破折号「——」算 2 个字符，拼音须对应 2 个空位（历史 bug：曾误写为单 token 导致错位，已修）。
- 书名号「《》《》」在作者/出处字段中按标点处理，不注音。

### 5.4 必会字词词条规范化
- 原始数据存在「字（读音）」式词条（如 `景（yǐng）`），已统一转为纯汉字 `景` + 正确拼音 `yǐng`，保证 `w`/`wp` 对齐。

## 6. 复现 / 修补指南

### 6.1 本地直接修改
1. 用浏览器打开 `心奇学古文.html`，定位问题篇目/年级。
2. 用编辑器打开文件，搜索篇名（如 `t:"观沧海"`）定位数据对象。
3. 修改字段后，务必保持 §5.1 对齐规则。
4. 校验（见下）→ 重新部署。

### 6.2 批量注入/校验脚本（Node.js）
以下脚本可复用于校验与批量补数据（历史上用于注入 `tp`/`ap`/`wp`、对齐检查）：
```js
// 1) 语法检查
node --check <(提取的 script)    // 或写入临时 _inline.js 后 node --check _inline.js

// 2) 拼音对齐校验（覆盖 L / tp / ap / wp）
var fs = require("fs");
var code = fs.readFileSync("index.html","utf8")
              .match(/<script>([\s\S]*?)<\/script>/)[1]
              .split("var gradeSel")[0];   // 仅取数据+纯函数部分（不含 DOM）
var POEMS; eval(code);
Object.keys(POEMS).sort().forEach(function(k){
  POEMS[k].forEach(function(p){
    // 正文
    p.L.forEach(function(line){
      if(!line[1]) return;
      var c=Array.from(line[0]), py=line[1].split(/\s+/).filter(x=>x!=='');
      if(c.length!==py.length) console.log('错位',k,p.t,'字'+c.length,'音'+py.length);
    });
    // 标题/作者/字词
    checkAlign(p.t, p.tp); checkAlign(p.a, p.ap);
    p.w.forEach(function(w,i){ checkAlign(w, p.wp[i]); });
  });
});
function checkAlign(t,py){
  if(!py) return;
  var c=Array.from(t), p=py.split(/\s+/).filter(x=>x!=='');
  if(c.length!==p.length) console.log('对齐错误', JSON.stringify(t));
}
```
```js
// 3) 注入必会字词拼音（示例：从正文 L 构建 字→音 映射，再生成 wp）
// 思路：遍历每篇 L，用 Array.from(中文) 与 拼音分词 建立 Map，
```

### 6.3 数据扩展（新增/合并数学等）
- 新增学期：在 `POEMS` 增 key（如 `"4s-math"`），并在 `renderSide`/`curKey` 逻辑中适配；或保持现年级 key 体系，另起独立 `POEMS2` 与切换器。
- 合并数学应用：将 R2 的 `POEMS` 结构（含题型字段）并入，扩展 `teachHTML`/`selfHTML` 分支渲染题型示例/练习题。

### 6.4 部署（发布链接）
- 使用 `workbuddy_cloudstudio_deploy` 工具，参数 `directory` 指向应用所在文件夹（单文件直接传目录即可）。
- 部署后获得 `https://*.app.workbuddy.link` 形式链接，**链接不变**（重新部署更新同一应用）。
- 历史已知：部署偶发 400/401，重试即可。
- 管理/删除：WorkBuddy「设置 - 数据管理 - 我发布的应用」。
