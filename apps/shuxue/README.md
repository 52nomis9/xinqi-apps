## 3. 设计思路

### 3.1 总体架构
- **单文件交付**：样式、骨架、数据、逻辑全部内嵌在一个 HTML 文件中，离线可用、易于分发与部署。
- **数据驱动渲染**：页面内容由 `UNITS` 数据对象驱动，改数据即改内容，新增/修改章节无需改逻辑代码。
- **参考古文应用**：布局、折叠侧栏、信息弹窗、工具栏交互均沿用「心奇学古文」成熟方案，降低维护者学习成本。
- **拆分-合并工作流**：开发时数据按年级拆分在 `data1~3.js`，发布时用脚本合并成单文件，兼顾可维护性与单文件交付。

### 3.2 关键设计决策
| 决策 | 说明 |
|------|------|
| 数据结构化 | 每章为一个对象，含 `review/teach/mind/examples/exercises`，字段含义见 §6.1 |
| 练习答案隐藏 | 用 `.exlist .ans{display:none}` + `.on{display:block}` 控制，点击切换；「全部显示」遍历切换 |
| 打印优化 | `@media print` 下隐藏侧栏与工具栏，并强制 `.exlist .ans{display:block!important}` 展开全部答案 |
| 字体缩放 | 通过 CSS 变量（`--fs-*`）统一控制，JS 中 `applyFont()` 按 `fontScale` 写入 px |
| 思维导图 | 用 SVG 动态生成（`mindmap(center, branches)`），无需外部图库 |

## 4. 系统结构与组件

### 4.1 目录结构
```
心奇学数学/
├── 心奇学数学.html        # 发布版单文件（= index + data1~3 合并）
├── index.html             # 框架（CSS + 骨架 + 逻辑脚本）
├── data1.js               # 数据：一~三年级（1s~3x，共 6 学期）
├── data2.js               # 数据：四~六年级（4s~6x，共 6 学期）
├── data3.js               # 数据：七~九年级（7s~9x，共 6 学期）
└── 心奇学数学v1.0(20260826)_readme.md  # 本文档
```

### 4.2 页面骨架（HTML）
- `.layout`（flex 横向）：左侧 `.sidebar` + 右侧 `.main`。
- `.sidebar`：`.side-head`（标题 `#appTitle` + 学期选择 `#gradeSel`/`#termSel`）+ `.collapse-btn`（`#collapseBtn`）+ `.side-nav`（`#sideNav` 目录）。
- `.main`（`#main`）：由 JS 动态填充 `toolbarHTML` + 页面内容。
- `#infoModal`：点击标题弹出的信息弹窗。

### 4.3 关键函数（script 内）
| 函数 | 作用 |
|------|------|
| `mindmap(center, branches)` | 生成思维导图 SVG |
| `curKey()` | 取当前 `年级+学期` 的 key（如 `"4s"`） |
| `pageHead(u, key)` | 生成页头（学期面包屑 + 标题 + 知识点说明） |
| `examplesHTML(u)` | 生成题型示例区（5 题，答案直接显示） |
| `exercisesHTML(u)` | 生成练习区（10 题，答案默认隐藏 + 逐题切换按钮） |
| `teachHTML(u, key)` | 教学页 HTML（启发回顾/教学解读/思维导图/题型示例） |
| `selfHTML(u, key)` | 练习页 HTML（10 道经典练习题） |
| `renderSide()` | 渲染左侧目录，绑定「教学/练习」按钮事件 |
| `show(i, m)` | 主渲染：组装工具栏 + 页面，绑定字体/打印/答案事件 |
| `toolbarHTML(isSelf)` | 顶部工具栏（A−/A+、打印[仅教学]、答案全部显示[仅练习]） |
| `toggleAll()` | 全部答案显示/隐藏切换 |
| `applyFont()` | 按 `fontScale` 写入 CSS 变量实现字体缩放 |

## 5. 用户界面与操作说明

### 5.1 总体布局
- 左上角：标题「心奇学数学」（点击弹出信息弹窗）+ 年级下拉 + 学期下拉。
- 标题下方：「«」折叠按钮，点击侧栏缩到最窄（仅留箭头），再点「»」展开。
- 左侧目录：当前学期章节列表，每章行 = 序号 + 标题 + 「教学」「练习」两个按钮。
- 右侧主区：顶部工具栏 + 页面内容（教学页或练习页）。

### 5.2 操作指引
| 操作 | 方法 |
|------|------|
| 切换学期 | 左上角选年级（一~九年级）+ 上册/下册，目录即时刷新 |
| 进入教学页 | 点击目录整行，或点击章节右侧「教学」按钮 |
| 进入练习页 | 点击章节右侧「练习」按钮 |
| 查看应用信息 | 点击左上角标题「心奇学数学」弹窗，含「使用方法」与「应用信息」 |
| 调整字体 | 内容页左上角 `A−`/`A+`，范围 70%~160%，步长 15% |
| 打印 | 教学页工具栏「🖨 打印」；打印时自动展开全部答案 |
| 逐题看答案 | 练习页每道题下方「显示答案」，点击展开（变「隐藏答案」） |
| 全部看答案 | 练习页工具栏「答案全部显示」→ 全部展开（按钮变「答案全部隐藏」），再点恢复 |

### 5.3 教学页内容结构
1. **启发回顾**：绿色提示块，串联已学旧知（如单位换算、前置知识）。
2. **教学解读**：条目化讲解本课核心知识，关键概念加粗。
3. **思维导图**：SVG 分支图，中心为本课标题，分支为知识点。
4. **题型示例（5 题）**：每题「题目 + 答」直接展示。

### 5.4 练习页内容结构
1. 顶部提示「对应章节经典练习题 10 题」。
2. 10 道题，答案默认隐藏；可逐题展开或一键全部展开/隐藏。

## 6. 数据与接口规范

### 6.1 数据结构
```js
UNITS = {
  "4s": [   // 学期 key：年级数字(1~9) + 学期字母(s=上, x=下)
    {
      no: 2,                    // 章节序号（显示「第 N 章」）
      title: "公顷和平方千米",   // 章节标题
      know: "较大的土地面积单位", // 知识点标签（显示在页头 meta 区）
      review: "…回顾文本…",      // 启发回顾
      teach: "<ul><li>…</li></ul>", // 教学解读（HTML 字符串）
      mind: [ {t:"长度单位", d:"mm/cm/dm/m/km"}, … ],  // 思维导图分支
      examples: [ {q:"…题目…", a:"…答案…"}, … ],      // 5 题
      exercises: [ {q:"…题目…", a:"…答案…"}, … ]      // 10 题
    }, …
  ], …
};
```

### 6.2 数据规范
- 学期 key 共 18 个：`1s,1x,2s,2x,3s,3x,4s,4x,5s,5x,6s,6x,7s,7x,8s,8x,9s,9x`。
- `examples` 固定 5 题、`exercises` 固定 10 题（维护时请保持，`renderSide` 顶部与弹窗会引用）。
- `mind` 分支 3~6 个为宜，`t` 为分支标题、`d` 为补充说明。
- `teach` 为 HTML 字符串，常用 `<ul><li>`，加粗用 `<b>`。

### 6.3 校验脚本（Node.js）
```js
global.window = global;
require('./data1.js'); require('./data2.js'); require('./data3.js');
var keys = ['1s','1x','2s','2x','3s','3x','4s','4x','5s','5x','6s','6x','7s','7x','8s','8x','9s','9x'];
var errs = [];
keys.forEach(function(k){
  (UNITS[k]||[]).forEach(function(u){
    if((u.exercises||[]).length !== 10) errs.push(k+' '+u.title+' 练习≠10');
    if((u.examples||[]).length !== 5)  errs.push(k+' '+u.title+' 示例≠5');
    if(!u.review || !u.teach || !(u.mind||[]).length) errs.push(k+' '+u.title+' 缺字段');
  });
  if(!(UNITS[k]||[]).length) errs.push(k+' 缺数据');
});
console.log(errs.length ? errs.join('\n') : '全部校验通过：18 学期、'+Object.values(UNITS).flat().length+' 章');
```

### 6.4 合并为单文件（发布前执行）
```js
// node merge.js —— 把 index.html + data1~3.js 合并为 心奇学数学.html
var fs = require('fs');
var html = fs.readFileSync('index.html','utf8');
var d1 = fs.readFileSync('data1.js','utf8');
var d2 = fs.readFileSync('data2.js','utf8');
var d3 = fs.readFileSync('data3.js','utf8');
var inline = '<script>\n' + d1 + '\n' + d2 + '\n' + d3 + '\n</script>';
// 用精确字符串替换三行 <script src="..."> 占位
html = html.replace(
  '<script src="data1.js"></script>\n<script src="data2.js"></script>\n<script src="data3.js"></script>',
  inline
);
fs.writeFileSync('心奇学数学.html', html);
```

## 7. 遗留问题与规避

| # | 问题 | 现状与规避 |
|---|------|-----------|
| 1 | 教材版本微调 | 人教版 2022 课标修订版偶有章节次序/内容调整（尤其小学中低年级），后续如有 2026 秋最新目录，按官方目录微调 `UNITS` 即可。 |
| 2 | 练习题覆盖面 | 每题每章固定 5 示例 + 10 练习，个别章节题型未穷尽教材全部变化；如需更全可扩充 `exercises`（注意保持题目数一致便于维护约定）。 |
| 3 | 答案正确性 | 数据均为人工/半自动整理，个别计算题答案可能存在笔误；发现后按 §6.1 定位章节修改即可。 |
| 4 | 初中目录深度 | 初中章节按人教版「章」级整理，未细分到「节」（如《全等三角形》下小节）；如需节级目录可在 `UNITS[key]` 中新增条目并按 `no` 排序。 |
| 5 | 字体缩放范围 | 缩放基于 CSS 变量，打印时按缩放后尺寸输出；超大字号可能影响打印分页，属正常现象。 |

直接用浏览器打开 `心奇学数学.html` 即可，无需服务器、无需联网。

## 9. 维护指南

1. **改内容**：打开 `data1~3.js`，按 §6.1 结构定位章节（可搜 `title:"公顷和平方千米"`），修改对应字段。
2. **加章节**：在对应学期数组中 `push` 一个对象（`no` 为该章序号，需与已有章节排序一致；也可直接更新序号）。
3. **加学期**：在对应 data 文件末尾 `UNITS['9x'] = [...]` 新增 key；如新增 10 年级需同步更新 `GRADES` 数组与 `GRADES` 渲染逻辑。
4. **改样式**：编辑 `index.html` 中 `<style>`，CSS 变量集中在 `:root`，便于整体换肤。
5. **改交互**：逻辑集中在 `index.html` 内联 `<script>`，按 §4.3 函数清单定位。
6. **校验**：每次改动后执行 §6.3 校验脚本 + `node --check`，确认无错后再合并发布。
