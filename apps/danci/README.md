## 一、目的需求（Purpose & Requirements）

### 1.1 项目目标
基于 **2025–2026 年上海教育出版社（沪教版，2022 课标修订版，三年级起点）小学英语教材（3–6 年级上、下册）** 单词表，开发面向小学生的英语单词**自学 / 复习 / 测评**应用「心奇学单词」。

交付形态为**单文件 HTML**（CSS/JS 全内联、零外部依赖、可离线运行），双击即可在任意现代浏览器打开使用，无需联网、无需服务器、无需安装。

### 1.2 核心需求
| 维度 | 要求 |
|------|------|
| 教材来源 | 单词必须**严格来源于沪教版 3–6 年级教材**，不得杜撰；释义、注音、造句、分级需与教材一致 |
| 掌握分级 | 三级：核心词汇（粗体展示）、二级词（加 `*`）、一般要求 |
| 练习 | 按教材顺序逐个学习，可展开造句与扩展记忆供抄写 |
| 测评 | 卡牌翻面随机抽题、人工判题、正确率统计与鼓励语 |
| 统计 | 按年级-上/下册-掌握程度三维度可视化 |
| 个性化 | 可设置姓名、年级（联动默认范围）、答题模式、抽取权重、鼓励语 |
| 数据 | 浏览器本地持久化 + JSON 导入/导出作为备份迁移通道 |

### 1.3 页面结构（共 5 页）
主界面（Home）· 设置页（Settings）· 词汇表页（Wordbank，原"题库"）· 练习页（Practice）· 测评页（Assessment）

## 二、设计思路（Design Rationale）

1. **单文件 + 零依赖**：所有 CSS/JS 内联，单个 `.html` 文件即完整应用，便于分发、双击运行与静态托管，最大化降低使用门槛（面向制造型企业办公室打工人及小学生家长）。
2. **离线可用 + 本地优先**：数据存浏览器 `localStorage`，刷新/关闭不丢失；不依赖任何后端，保护隐私且零运维成本。
3. **儿童友好视觉**：淡蓝色主色系、卡通可爱边框、按钮前置彩色 emoji、大字号、清晰层级，降低小学生使用认知负担。
4. **分级与权重驱动的智能抽题**：基于「答对率分档（F→A 六档）」的反向加权抽样——**越不会的词越容易被抽到**，让复习精准命中薄弱点；练习/测评权重系数各自独立可调。
5. **教材忠于来源 + 可循环迭代**：内置 1280 词沪教版真实词库；应用内提供词库 JSON 导出/导入，支持"备份 → 批量修改 → 再导入"，实现教材更新与自编词库的可循环迭代。
6. **可视化反馈**：练习用 SVG 玫瑰图（南丁格尔图）展示各年级掌握程度；统计用 SVG 堆积扇形图呈现「年级-册-分级」三层结构，悬停显示明细。

## 三、系统结构与组件（System Architecture & Components）

### 3.1 技术栈
- 纯 HTML + 内联 `<style>` + 内联 `<script>`（ES5/ES6 混用，无构建步骤）
- 图表：手写 SVG（无第三方图表库）
- 存储：`localStorage`（key = `wb_xinqi_state_v2`）

### 3.2 顶层常量
| 常量 | 值 | 说明 |
|------|----|------|
| `APP_VERSION` | `'1.0'` | 应用版本 |
| `STORE_KEY` | `'wb_xinqi_state_v2'` | localStorage 键 |
| `VOCAB_VERSION` | `'sh2022-1'` | 词库版本标识（迁移兼容用） |
| `GRADES` | `[3,4,5,6]` | 支持年级 |
| `SEM` | `{1:'上册',2:'下册'}` | 册别 |
| `LEVEL` | `{1:'核心词汇',2:'二级词',3:'一般要求'}` | 分级 |
| `BAND` | 见下 | 答对率分档（颜色/权重/标签） |
| `DEFAULT_ENCOURAGE` | A–F 六级英+中鼓励语 | 测评完成反馈 |

**BAND（答对率分档）表**
| 档 | 标签 | 颜色 | 权重 | 答对率区间 |
|----|------|------|------|-----------|
| F | 未测评 | `#ffffff`（白） | 5 | — |
| E | ≤20% | `#f8a5c2`（粉） | 10 | 0–20% |
| D | 20–40% | `#ffb088`（淡橙） | 5 | 20–40% |
| C | 40–80% | `#ffe08a`（淡黄） | 3 | 40–80% |
| B | 80–95% | `#9ad0f5`（淡蓝） | 2 | 80–95% |
| A | 95–100% | `#a8e6a3`（淡绿） | 1 | 95–100% |

命中概率 = 单词权重 ÷ 范围内总权重（权重越大越易抽中 → 不会的词更易被抽中）。

### 3.3 核心函数一览
| 函数 | 职责 |
|------|------|
| `buildWords()` | 将 `VOCAB` 数组映射为词对象数组（含 `id`/`draw`/`correct` 初值） |
| `defaultSettings()` | 返回默认设置（练习/测评独立 range/levels/权重/count；鼓励语；统计范围） |
| `normalizeSettings(s)` | 兼容旧版设置结构（grades→range、顶层 weight 兼容等） |
| `loadState()` / `saveState()` | 读取/写入 localStorage；词库版本不符自动替换词库并保留设置 |
| `renderHome/renderSettings/renderWordbank/renderPractice/renderAssessment` | 五大页面渲染 |
| `exportSettings()` / `exportVocab()` / `importData()` / `doImport()` / `applyPendingImport()` | 设置与词库的导入导出（同一选择器识别三类 JSON） |
| `exportWbPrint()` | A4 双栏打印清单 |
| `weightedSample(pool,n,wFn)` | 加权抽样 |
| `bandOf(w)` / `weightOf(w,weights)` / `accOf(w)` / `accText(w)` | 答对率→分档、权重、百分比文本 |
| `filterWords(range,levels)` / `textbookOrder(...)` | 按范围/分级过滤、教材顺序排序 |
| `openHelp()` / `openAbout()` / `openModal()` | 弹窗与使用说明/应用信息 |

### 3.4 页面与组件映射
- **主界面**：今日复习建议、使用说明、应用信息、导出/导入设置参数、生成练习/测评入口。
- **设置页**：① 个人信息（姓名、年级）② 练习设置（范围/展示内容/抽题数量/权重）③ 测评设置（范围/抽题数量/答题模式/鼓励语/权重）④ 统计分析（堆积扇形图 + 一键恢复默认）。
- **词汇表页**：全部单词的教材来源、分级、释义、注音、测评记录（被抽/答对/答对率）；可增删改、导入教材词库、导出打印清单（A4）。
- **练习页**：按教材顺序逐个展示，点「展开」看造句与扩展记忆。
- **测评页**：卡牌翻面、按遮挡人工判题 ✔/✘，完成弹窗显示正确率/得分/鼓励语。

## 四、用户界面与操作说明（UI & Operations）

### 4.1 通用
- 主标题：`🔤 心奇学单词`；副标题：`Sophia & George English Words Learning App`。
- 顶部/底部导航切换五大页面。
- 练习/测评进行中：主界面功能区禁用；两页均提供「强制退出」按钮（确认后退出，**不记录本次数据**）。

### 4.2 主界面
| 功能 | 操作 |
|------|------|
| 使用说明 | 弹窗介绍各页面 |
| 应用信息 | 版本、更新日期、作者（Peppa's Daddy）、更新日志 |
| 导出设置参数 | 导出 `{app,version,vocabVersion,settings}` JSON |
| 导入设置参数 | 选择 JSON，识别「仅设置 / 仅词库 / 完整备份」三类，覆盖前确认（版本不一致弹窗提示） |
| 生成练习页 / 生成测评页 | 跳转并按设置生成 |

### 4.3 设置页
1. **个人信息**：英文名（默认 Sophia）、年级（默认 3）。年级联动调整各模块默认范围，可手动覆盖。
2. **练习设置**：生成范围（勾选年级-上/下册 + 程度级别）、展示内容勾选（单词/音标/释义/造句/扩展记忆）、**抽题数量**（默认 10）、抽取权重（F→A）。
3. **测评设置**：生成范围、**抽题数量**（默认 10）、答题模式（中测英/英测中/混合）、鼓励语、抽取权重。
4. **统计分析**：勾选范围（默认 3–6 年级），堆积扇形图展示各年级掌握程度；**恢复默认设置**一键重置。

### 4.4 词汇表页
- 可按年级-上/下册、分级筛选；显示被抽次数/答对次数/答对率。
- 「编辑」「删」同行操作；「导入教材词库」按 JSON 规则批量导入；「导出打印清单（A4）」生成紧凑双栏复习清单（不含造句/联想），支持打印/另存 PDF。

### 4.5 练习页
按教材顺序逐个展示单词基本内容；点「展开」显示造句与扩展记忆，供学习与抄写。

### 4.6 测评页
- 卡牌呈现：卡背=序号，点击沿纵轴翻转；正面=中文/英文/读音 + 判题区。
- 按设置用灰雾遮挡中文或英文；点击判题区灰雾消失，出现绿色 ✔ / 红色 ✘ 供人工判题。
- 判题后数据写回词库；未完成判题不可点其他卡牌。
- 全部完成弹窗显示正确率、得分、鼓励语（A–F 六级，英语 + 汉语）。

## 五、数据与接口规范（Data & Interface Spec）

### 5.1 本地存储（localStorage）
- 键：`wb_xinqi_state_v2`
- 结构：`{version, vocabVersion, settings, words}`
- 加载时若 `vocabVersion !== VOCAB_VERSION`，则用新内置词库替换 `words`（保留用户设置，旧测评记录随旧词库作废）。

### 5.2 单词对象（word object）schema
每个词包含 12 个字段：
```js
{
  id:        'v1',          // 唯一标识
  word:      'happy',       // 英文
  phonetic:  '/ˈhæpi/',     // 音标（可空）
  meaning:   '开心的',       // 中文释义
  sentence:  'I am happy.', // 造句（可空）
  memory:    '词根联想…',     // 扩展记忆（可空）
  grade:     3,             // 年级 3–6
  semester:  1,             // 册 1=上册 2=下册
  unit:      1,             // 单元 1–12；90=专有名词 91=星期 92=数字 93=月份 94=基数词 95=序数词
  level:     1,             // 分级 1=核心 2=二级 3=一般
  draw:      0,             // 被抽次数（测评记录）
  correct:   0              // 答对次数（测评记录）
}
```

### 5.3 内置词库数组（VOCAB）格式
`buildWords()` 将如下二维数组映射为 word 对象：
```js
// 词条：[英文, 音标, 释义, 造句, 扩展记忆, 年级, 册(1上2下), 单元, 分级]
['happy','/ˈhæpi/','开心的','I am very happy today.','词根联想…',3,1,1,1]
```

### 5.4 设置对象（settings）schema
```js
{
  name: 'Sophia',
  grade: 3,
  encourage: {A:{en,zh}, B:{en,zh}, ... F:{en,zh}},
  practice:  {range:{3:[1,2],4:[1,2],5:[1,2],6:[1,2]}, levels:[1,2,3],
              display:{word,phonetic,meaning,sentence,memory:true},
              ratio:'proportional'|'all', count:10, weight:{F:5,E:10,D:5,C:3,B:2,A:1}},
  assessment:{range:{...}, levels:[1,2,3],
              ratio:'count'|'all', count:10, mode:'mixed'|'c2e'|'e2c',
              weight:{F:5,E:10,D:5,C:3,B:2,A:1}},
  stats: {grades:[3,4,5,6]}
}
```

### 5.5 导入/导出 JSON 三类格式（同一选择器识别）
`importData()` + `doImport()` 通过判断字段自动识别并分别给覆盖提示：
1. **仅设置**：`{app, version, vocabVersion, settings}`
2. **仅词库**：`{app, version, vocabVersion, exportedAt, words:[...]}`
3. **完整备份**：同时含 `settings` 与 `words`

`exportVocab()` 输出：
```json
{
  "app": "心奇学单词",
  "version": "1.0",
  "vocabVersion": "sh2022-1",
  "exportedAt": "2026-08-26T...",
  "words": [ /* 词对象数组，含全部 12 字段 */ ]
}
```
文件名：`心奇学单词-教材词库-<N>词-<10位时间戳>.json`

## 六、遗留问题与规避（Known Issues & Workarounds）

| # | 问题 | 规避 / 说明 |
|---|------|------------|
| 1 | 词库版本变化会**整体替换** `words`，旧测评记录（draw/correct）随旧词库作废 | 重大教材更新前先「导出教材词库」备份；版本迁移是预期行为，保留用户设置 |
| 2 | 打分纯人工（✔/✘），无自动语音识别/拼写判题 | 面向小学生刻意设计为「家长/老师陪练判题」，降低实现复杂度；如需自动判题需后续扩展 |
| 3 | 无音频朗读（TTS） | 当前仅展示音标文本；如需发音可后续接入 `SpeechSynthesis` API |
| 4 | 数据仅存单浏览器 localStorage，换设备/清缓存即丢失 | 用「导出设置参数 / 教材词库 / 完整备份」JSON 做迁移；跨设备需手动导出导入 |
| 5 | 测评模式固定按权重抽样，未测评词（F 档）默认权重 5，可能与已测评低分词抢配额 | 可调高 F 档权重；`DEFAULT_WEIGHT` 与设置页权重均可改 |
| 6 | 大词库（1280 词）全部内联，HTML 文件较大（约数十 KB–数百 KB） | 单文件分发可接受；如欲瘦身可改为外部 JSON 加载（需放弃纯离线单文件特性） |

## 八、维护指南（Maintenance Guide）

### 8.1 修改教材词库
- **方式 A（推荐，无需改代码）**：在应用内「词汇表页 → 导出教材词库」导出 JSON，批量编辑后「导入教材词库」载入（格式见 5.5）。
- **方式 B（直接改源码）**：编辑 `心奇学单词.html` 顶部 `VOCAB` 数组，并**务必同步修改** `VOCAB_VERSION`（如 `'sh2022-2'`），使 `loadState()` 触发词库替换。

### 8.2 修改默认设置
- 编辑 `defaultSettings()` 与 `DEFAULT_WEIGHT` / `DEFAULT_ENCOURAGE`；旧用户数据经 `normalizeSettings()` 兼容，无需强更。

### 8.3 修改抽题权重逻辑
- 调整 `BAND` 表权重或 `weightedSample()`；练习/测评权重在设置页各自独立，改动默认须同步 `DEFAULT_WEIGHT`。

### 8.4 修改视觉风格
- 全局 CSS 在 `<style>` 内，主色系为淡蓝；emoji 图标集中在导航/按钮/弹窗文案中（如 `🔤` 主标题、`🧒` 个人信息、`📚` 词汇表、`✏️` 练习、`🎯` 测评、`⚙️` 设置）。

### 8.5 版本发布流程
1. 改 `APP_VERSION` 常量与「应用信息」弹窗的版本/日期/更新日志 `<li>`。
2. 同步更新本文档（版本日志、相关说明）。
3. `cp 心奇学单词.html deploy/index.html` 并重新部署（链接不变）。
4. 将 `心奇学单词.html`、`心奇学单词-readme.md` 归档到发布目录。
