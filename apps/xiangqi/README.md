# 心奇学象棋（Xiangqi 3D）

纯静态、零依赖的中国象棋网页游戏，春秋战国风 3D 渲染。规则由独立引擎实现，**双击 `index.html` 即可在浏览器中游玩**，无需安装 npm / Vite / React，也无需联网（three.js 已本地化到 `vendor/`）。

---

## 运行方式

### 方式一：直接打开
双击目录中的 `index.html`，使用任意现代浏览器（Chrome / Edge / Firefox / Safari）打开即可。需要浏览器支持 WebGL。

### 方式二：本地静态服务（推荐）
在项目目录执行：

```bash
cd xiangqi-game
python -m http.server 8000
```

然后访问 <http://localhost:8000> 。

## 功能总览（V3+V4）

1. **主标题**：正上方标题为「心奇学象棋」，标题右侧有可点击的侧栏折叠/展开按钮（点击后棋盘区会自动拉满）。
2. **棋子形象 3 风格**：右侧「棋子形象」切换——**模型**（纯 3D 模型，无标牌）、**模型+汉字标牌**（悬浮汉字悬浮牌）、**汉字**（圆角扁平圆柱 + 隶书汉字，无人物模型）。
3. **棋谱导入 / 导出 / 复盘**：`导入棋谱`、`导出棋谱` 按钮；点击着法记录中的某一步会浮现「复盘重下」，点击后删除该步之后的所有着法并从此步续下。
4. **配色与将帅**：整体棋盘/棋子配色加深，不再刺眼；将/帅为**坐于宝座的帝王模型**（花纹长袍 + 冠冕 + 双手搭在两侧扶手上），红/黑袍色区分，明显高于其他棋子。
5. **吃子提示**：选中己方棋子后，可走格显示绿点，**可吃子的格底部加蓝色外圈**标示。
6. **让子**：「难度设置」中包含**让子方**选择（红方让子 / 黑方让子，默认红方让子），以及让子种类（常规 / 让单马 / 让单车 / 让双炮 / 让双车 / 让车马炮）。**让子方**决定哪些棋子被移除（中心对称映射）；调整让子方 / 让子种类都会即时重建当前开局局面。
7. **人机难度 1–7 级**：
    - 1 级 兵/卒级（初学）：明显漏棋
    - 2 级 仕/士级（新手）：偶尔漏棋
    - 3 级 相/象级（入门）：很少漏棋
    - 4 级 炮/砲级（业余）：不再漏棋
    - 5 级 马级（高手）
    - 6 级 车级（棋士）
    - 7 级 帅/将级（大师）
   默认 1 级，难度从 1 → 7 平滑递增（搜索深度、棋力评估逐步增强，4 级起失误为零）。
8. **战果展示**：主界面不再显示「战果」与「棋子形象」文字面板；**被吃掉的棋子始终以"汉字"样式的扁圆柱棋子（带隶书汉字）** 立放展示在棋盘外右侧，每行 5 个、最多 4 行，无背景，与"棋子形象"选择无关。
9. **音效**：在「轮下方」子版块右侧有一个喇叭 / 静音切换按钮（默认开）。开启时四类音效：
    - 提棋（点击己方棋子时）：略沉闷的短促拖动声
    - 落棋（棋子到达目的地）：清脆短促的木棋盘敲击声
    - 吃子：普通话「吃！」语音（紧跟落棋之后播放）
    - 将军：普通话「将军！」语音（在所有音效最后播放）

## 3D 特色

### 棋子形象（春秋战国风，程序化建模）
所有棋子为简单 3D 模型，人物着装、发型与器物参考春秋战国时代特点；「汉字」风格则用隶书汉字平铺于扁平圆盘上。

| 棋子 | 形象 |
| --- | --- |
| 兵 / 卒 | 小号 · 持长戈的朴素着装步兵（布衣束带） |
| 车 / 車 | 中号 · 春秋双人战车（车兵持戈 + 御者握缰、双轮军旗） |
| 马 / 馬 | 中号 · 持长矛的骑马骑士（青铜胄） |
| 炮 / 砲 | 中号 · 单人操作的投石车（配重投臂 + 石弹 + + 绞盘 + 操作手） |
| 相 / 象 | 大号 · 羽扇纶巾的文官（宽袍广袖、飘带纶巾） |
| 仕 / 士 | 大号 · 左盾右剑的近卫精英战士（披风青铜胄） |
| 将 / 帅 | 大号 · 坐于宝座、戴冠冕、双手搭在扶手上的帝王（花纹长袍，黑/红袍区分，明显更高） |

渲染采用 three.js `MeshToonMaterial`（4 级色阶卡通着色）+ 反向外壳描边，呈现卡通渲染质感。整体配色已调暗以降低刺眼感。

### 视角系统
- **45° 对局后方斜视**：默认从红方后方斜视；勾选「视角随走棋方切换」后，每走一步相机自动平滑转到当前走棋方身后（立场始终正确）。
- **90° 全程俯视**：一键切换全程正俯视；勾选「视角随走棋方切换」时，90° 俯视也会随走棋方翻转（走棋方朝下）。
- 「视角随走棋方切换」对 45° 与 90° 均生效：**勾选后视角锁定，无法再拖拽/触控调整**；取消勾选后才可自由拖拽旋转视角。滚轮缩放随时可用。
- 「翻转视角」按钮一键换边（45°/90° 均有效）。
- 右上角竖排两个按钮：**全屏（⛶，上）** 与 **侧栏折叠（❯/❮，下）**。点全屏让「棋盘下棋界面」全屏展示（原生全屏，iOS 等不支持时自动回退为全屏遮罩，Esc 退出）。

### 操作
- 左键点击己方棋子 → 高亮全部合法落点（**绿点 = 移动，绿点+蓝色外圈 = 吃子**）→ 点击落点走子。
- 点击可穿透：斜视时点击被前排棋子模型挡住的格子也能正确落子。
- 模式：双人对战 / 人机对战（玩家执红先走，电脑执黑，AI 1–7 级可调）。
- 悔棋（人机模式连电脑应着一起撤）、重新开始、终局弹窗、将军横幅、着法记录（传统记谱：红方汉字数字「马八进七」、黑方阿拉伯数字「砲2平3」）、棋盘外右侧的 3D 汉字棋子战果展示。

## 引擎 API（`engine.js`）

函数均接收/返回 `{ grid: Piece[10][9] | null, turn: 'red' | 'black' }`，走法对象为 `{ from: [c, r], to: [c, r], piece, captured }`。

| 函数 | 说明 |
| --- | --- |
| `createInitialBoard()` | 生成标准开局棋盘 |
| `generateLegalMoves(board, side?)` | 返回某方全部合法走法（已过滤送将 / 对脸） |
| `applyMove(board, move)` | 返回走子后的**新**棋盘（不修改原棋盘） |
| `isInCheck(board, side)` | 某方帅/将是否被将军 |
| `getGameStatus(board)` | 返回 `{ over, winner, reason }` |

`core.js` 额外提供：`createHandicapBoard(kind, giver)`、`aiMove(board, side, level)`、`exportGame(moveList, meta)`、`parseGameText(text)`、`replayNotations(startBoard, list)`、`computeCaptured(board, initialCounts)`、`moveToLE / notationToMove`。

## 测试结论

- 规则引擎：`node engine.test.js` → **19/19**；`node engine.extra.test.js` → **20/20**。
- 交互自动化（无头浏览器 CDP 实测）：标题/侧栏折叠/展开/板块顺序/让子方动态变化/难度命名与曲线/音效开关/战果汉字棋子始终 19/19 通过。
- 引擎与棋盘镜像在 Node 中验证：让子方为红方/黑方时，被移除棋子的格子按中心对称（180°）映射正确。

## 已知限制 / 说明

- **AI 强度**：1–7 级对应不同的搜索深度与失误率（1 级明显漏棋，4 级起失误为零）。可在 `core.js` 的 `LEVELS` 调整参数。
- **记谱简化**：未实现"前/后"同列同子区分。
- **无长将/重复局面判定**：未实现竞赛细则，仅按无合法着法判定终局。
- **纯前端**：棋局仅存内存，刷新即重置。
- **音效**：使用系统 SpeechSynthesis 合成普通话「吃！」/「将军！」（优先选用简体普通话语音 zh-CN，规避粤语/繁体语音；语音列表未就绪时自动等 voiceschanged 后再播，改善手机/平板上听不到的问题）；不同浏览器 / 系统对中文语音支持不同，若无声学能力会回退到合成的双音提示。
- **性能**：大量棋子为组合模型，低端设备上建议切换「汉字」风格或缩小窗口。
