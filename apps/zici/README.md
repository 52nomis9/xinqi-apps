## 1. 目的需求

### 1.1 应用目标

为小学 1~6 年级学生提供一套**离线可用的单文件**语文字词学习应用，覆盖统编版语文教材全部 12 个学期的**识字表（会认）、写字表（会写）、词语表**三表内容，包含：

- **学习**：拼音、笔画部首、字型结构、笔顺、**描红动画**、组词（含拼音+生活例句）、字源解析、形近字辨析；词语的释义、造句、近义词（含辨析）、反义词
- **测评**：识字/写字/词语/综合四种测评，抽测/全测模式，权重抽题，判题，得分
- **题库**：全库字词检索、学习信息查看与编辑、统计（抽测次数/正确率/掌握程度 6 档）、导出导入
- **统计**：每字词的抽测次数、正确率、掌握程度分级（F~A 六档配色+权重）

### 1.2 用户画像

- 小学 1~6 年级学生（核心使用者，儿童友好设计：温暖配色、大字号、清晰层级）
- 家长/老师（监督学习、查看测评记录、打印复习资料）

### 1.3 设计原则

1. **单文件、零依赖**：全部 HTML/CSS/JS/数据内联，双击即开，离线可用，可任意分享
2. **儿童友好**：温暖色系（淡玉红主色）、大字号、明确的层级结构、点击展开的交互
3. **数据真实**：字词表来自教材附录原文；组词/例句/字源/释义等来自权威词典（汉典等），多音字按课内读音
4. **可维护**：数据与逻辑分离（构建管线生成数据→注入模板），便于批量补充

## 2. 设计思路

### 2.1 整体架构

```
┌─────────────────────────────────────────────────────┐
│              心奇学字词.html（单文件应用）              │
│  ┌──────────┬──────────────────────────────────────┐ │
│  │ 左侧功能页 │          右侧内容页                    │ │
│  │ 标题栏🀄   │  ←当前功能对应的内容区                  │ │
│  │ 菜单栏     │  （题库/学习/测评/设置/查询）            │ │
│  │ 年级学期   │                                        │ │
│  │ 目录区     │  （左上角工具条：字号/打印/导出等）       │ │
│  └──────────┴──────────────────────────────────────┘ │
└─────────────────────────────────────────────────────┘
```

- **数据层**：内联的 `BOOKS`（12 学期教材结构）、`HANZI`（3036 字字典）、`CIYU`（2114 词字典）、笔画动画数据
- **逻辑层**：页面渲染（renderDir/renderTikuDir/renderXuexiDir/renderCepingDir/renderShezhi）、统计系统（getStat/levelOf）、测评引擎、笔画动画引擎、设置系统
- **持久层**：localStorage（设置、测评统计、字词掌握数据）

### 2.2 关键设计决策

| 决策 | 说明 |
|---|---|
| 单文件内联 | 数据构建期合并为 `window.BOOKS/HANZI/CIYU` 注入模板，零外部请求 |
| 识字≠写字归类 | 识字表=会认（shizi）、写字表=会写（xiezi）、词语表=ciyu，回归教材原始定义；同课同字在两表重复出现时**每个位置独立展示**（不去重） |
| 描红动画 y 轴翻转 | hanzi-writer-data 坐标系 y 轴朝上（bounds 0,-124~1024,900），渲染时用 `scale(1,-1) translate(0,-900)` 翻转修正（否则字形上下颠倒）；笔尖沿 medians 中线运动体现笔画方向 |
| 掌握程度 6 档 | F 白(未测,权重5)/E 粉红(≤20%,10)/D 淡橙(20-40%,5)/C 淡黄(40-80%,3)/B 淡蓝(80-95%,2)/A 淡绿(95-100%,1)；抽测概率=权重/总权重 |
| 多音字处理 | 课内读音（教材附件原文拼音）为主显示黑色，其他常见读音灰色，不含生僻读音 |
| 数据构建管线 | `_build/` 下脚本：解析教材附件→下载笔画→补拼音/部首/笔顺→抓取组词/字源/形近字/词语释义→例句生活化→合并注入 |

## 4. 用户界面与操作说明

### 4.1 总体布局

- **左侧功能页**（自上而下）：标题栏（🀄 心奇学字词，点击弹应用信息；🔍 查询按钮在最右侧）→ 功能菜单（题库/学习/测评/设置）→ 年级学期选择 → 目录区（可滚动）
- **右侧内容页**：随功能切换；左上角统一工具条（字号 A−/A+、打印等）
- 侧边栏可收起（☰ 按钮），收起后内容区自动扩展

### 4.2 题库页

- 目录：识字表🥇 / 写字表✏️ / 词语表🧩 三行按钮
- 内容：字词一行一个（单元·课程·字词·拼音），右侧统计列（抽测次数/正确次数/正确率/掌握程度 6 档配色）
- 右上角：堆积条状图（正确率级别占比）+ 平均正确率（未抽测不计入）
- 功能：字号、打印、批量导出（`心奇学字词_题库_年级学期_日期时间.json`）、批量导入
- 点击字词行 → 弹窗展示完整学习信息，可编辑保存（拼音/组词等）

### 4.3 学习页

- 目录：各单元课程，每课右侧「橙·识字 / 淡蓝·写字 / 淡绿·词语」按钮；无内容的课程按钮置灰；单元/学期汇总行也有三分类按钮
- **识字/写字页**（每字依次）：拼音声调 → 部首/结构/笔画数 → 笔画顺序（横、竖、撇…）→ **描红动画**（红色虚线田字格+灰色楷体，播放时红色笔尖按笔顺运动带方向箭头）→ 组词（每个词含拼音+例句，点击例句展开/收起）→ 字源解析（点击展开）→ 形近字辨析（点击展开）
- **词语页**：词语（拼音）→ 释义（多义项，每项配造句示例）→ 近义词（含含义用法辨析，点击展开）→ 反义词
- **汇总页**：单元/学期范围内该分类全部字词，一行一个字词+拼音，课程标题行淡色背景区分，不同单元间单元名分隔
- 左上角：字号调节、打印

### 4.4 测评页

- 目录：单元选择菜单（整个学期或具体单元）+ 识字测评🥇 / 写字测评✏️ / 词语测评🧩 / 综合测评🧮
- **模式**：抽测（1~100 题，权重抽题不重复；题数≥全测数则等效全测）/ 全测（默认设置可在设置页改）
- **方法**：识字=给字答读音/给读音写字/混合；写字=给字答读音（默认）/给读音写字/混合；词语=看拼音写词语（默认）/给词语答拼音/混合
- **题卡**：待测信息灰色遮挡（遮挡宽度=卡片 90%），点击显示答案；下方信息区左右为 ✔（绿）/×（红）判题按钮；判对字卡淡绿泛光、判错红色；每张卡需完成判题才能点下一张（不强制顺序）；判题后信息区显示最新分类/正确率
- 左上角：字号、打印；右上角：退出测评（已判题计入统计）
- 全部判完自动弹窗：得分（百分制取整）+ 回顾测评 / 重新测评 / 退出测评

### 4.5 设置页

- 顶部按钮组：💾 保存设置 / ↺ 恢复默认设置 / ⬇ 导出设置（`心奇学字词_设置_姓名_日期时间.json`）/ ⬆ 导入设置
- **应用设置**：🧒 姓名（默认"心奇"）、年级、布局（功能/内容区尺寸）、目录区字号、默认初始年级学期
- **题库设置**：题库字号初始值、清除正确率（二次确认后抽测及正确率归零）
- **学习设置**：学习页字词卡尺寸初始值
- **测评设置**：测评页题卡尺寸、抽测模式（抽测+题数）、三类测评方法、正确率权重系数（F~A 每级）
- **数据统计**：按年级学期顺序，每学期一行堆积条状图（正确率级别占比）+ 平均正确率（未抽测不计入）

### 4.6 查询功能

- 点击标题栏右侧 🔍 → 年级学期选择区变为输入框+放大镜，目录区变为检索结果区
- 输入字/词回车或点放大镜 → 按年级课程先后顺序逐行显示（格式：`字词 年级-学期-单元-课程-分类`），显示命中数
- 点击任一结果 → 自动切换年级学期并跳转到对应课程学习页

### 4.7 应用信息弹窗

点击主标题 → 显示应用简介（应用简介/题库/学习/测评/设置五部分用法说明）、版本 v1.0、更新日期、作者 Peppa's Daddy。

### 5.3 统计与权重

```
掌握级别（按正确率）：
F 未测评（白，权重5）| E ≤20%（粉红，10）| D 20-40%（淡橙，5）
C 40-80%（淡黄，3） | B 80-95%（淡蓝，2）| A 95-100%（淡绿，1）

抽测概率 = 该字词权重 / 抽取范围总权重
平均正确率 = 正确次数合计 / 抽测次数合计（未抽测不计入）
```

## 6. 遗留问题与规避

| # | 问题 | 现状/规避 |
|---|---|---|
| 1 | 18 字缺部首（cnchar 数据源缺失） | 应用显示空部首，不影响使用；可题库页编辑补充 |
| 2 | ~90 字形近字缺失 | 算法未生成，应用不显示该区块；可按 meta_curated_xj 格式补策展 |
| 3 | 部分词语释义带书证原文（如"严寒"含《咏怀》书证） | 词典真实出处，属可接受；可逐词润色为纯白话 |
| 4 | 个别字音为 pinyin-pro 判读（四上~六下附件无拼音） | 可题库页弹窗编辑；持久化需改数据源重建 |
| 5 | 部分词语无近义词/反义词 | 词本身无语义对立词，应用自动隐藏对应区块（正常现象） |
| 6 | 单文件 ~10.3MB | 首次加载 2-3 秒，浏览器缓存后秒开；如需精简可只内嵌需要的学期数据 |
| 7 | 题库编辑保存仅内存级（刷新丢失） | 编辑用于临时校对；正式修改需改数据源（_build 管线）后重新构建 |
| 8 | 简体字笔画数据缺失个别生僻字 | 3036 字全覆盖，无此问题（含扩展区字用 codePoint 编码存储） |

## 7. 部署与配置

### 7.1 本地使用（最简单）

1. 双击 `心奇学字词.html` → 浏览器直接打开（file:// 协议可用，localStorage 正常）
2. 手机：把 html 文件传到手机 → 用浏览器打开 → 分享/添加到主屏幕

## 8. 维护指南

### 8.1 重新构建（完整流程）

```bash
cd _build
node parse_full.js                    # 1. 解析教材附件 → lessons_data_full.js（如无新附件可跳过）

node scrape_gradeN.js                 # 4. 抓取 N 年级组词/字源/形近字（缓存 _probe/cache_g1/，断点续传）

node inject.js                        # 7. 注入模板 → 心奇学字词.html
node runtime_test.js                  # 8. jsdom 运行时测试（50 项）
```

### 8.2 补充/修正单字内容

1. 直接编辑对应策展文件（`meta_curated_g1/g2/g3456.js`），按现有格式加条目
2. 重新 `node build.js && node inject.js`

### 8.3 生活化例句修正

- 模型生成批次在 `_build/_fix/meta_eg_g*.js`；手写补充在 `_fix/meta_eg_final.js`（格式：`{"字":{"词":"例句"}}`）
- 新增批次需在 `build.js` 中加载并在 `fixZcItem()` 的覆盖链中登记

### 8.4 近义词辨析

- 策展文件 `_fix/meta_jy_g2.js`（二年级）+ `_fix/meta_jy_g3456_p1~12.js`（三~六年级）

- build.js 中 `META_JY_G3456` 合并后按词覆盖抓取数据（未策展词清空 jy）
